# Museums Open Data Portal
Users can search, filter, and view detailed information about museums through an intuitive interface. The application is fully containerized and available to run on Docker.
## Technologies used:
* Spring
* React
* Docker

## Dataset information
### Description

This dataset includes basic information about museums around the world, including their locations, type and scope of collections, annual visitor numbers, and additional digital resources such as official websites and virtual tours.

### Attribute Description

* Name
* Country
* City
* Year Established
* Type of Museum (e.g. art, history)
* Collection Size (total number of items held by the museum)
* Visitors (annual number of visitors calculated for the year 2023)
* Exhibition Space (area of exhibition space in m<sup>2</sup>)
* Website (official website of the museum)
* Virtual Tour (whether the museum offers a virtual tour)
* Exhibits (a selection of 2 exhibits held by the museum)

  * Name
  * Type (e.g. painting, sculpture)
